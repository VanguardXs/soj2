# СӨЖ №2 — Бір бет, үш стиль

Бұл жоба СӨЖ №1 сандық визиткасының үш CSS нұсқасынан тұрады. Басты файл `index.html`: онда барлық нұсқаға сілтеме бар.

| Файл | Мәні |
| --- | --- |
| `inline.html` | Тек элементтердің `style` атрибуттары |
| `internal.html` | CSS ережелері `<head><style>...</style></head>` ішінде |
| `external.html` | `style.css` файлы `<link>` арқылы қосылған |
| `priority.html` | Үш тәсілдің `color` басымдығын көрсету |
| `salystyru.md` | Салыстыру кестесі мен скриншот нұсқаулығы |
| `assets/` | Визиткаға ортақ сурет пен favicon |

Браузерде алдымен `index.html` файлын аш. Үш визитканы бірдей терезе өлшемінде салыстыр. `:hover` тек ішкі және сыртқы CSS нұсқаларында жұмыс істейді, себебі style атрибуты селекторларды қабылдамайды. `priority.html` файлын DevTools-та ашып, қолданылған және басылған `color` ережелерінің скриншотын өзің түсір.

**GitHub-қа тапсыру:** жаңа репозиторийге осы бумадағы дайын файлдарды және `assets` бумасын бірге жүкте. Репозиторий сілтемесін тапсырмаға жаз. Егер GitHub Pages қоссаң, басты `index.html` арқылы үш бетті ашуға болады. Скриншотты салғаннан кейін `salystyru.md` кестесін немесе Word нұсқасын бірге тапсыр.

СОӨЖ №2 сабақта оқытушы берген CSS қателеріне тәуелді жеке жұмыс; бұл жинақ СӨЖ №2 үшін.
